# 🐱 Cat Game

고양이를 조종해 물고기를 먹는 스네이크 스타일 웹 게임입니다. 설치나 빌드 없이 바닐라 HTML/CSS/JavaScript만으로 만들었습니다.

## 실행 방법

`index.html`을 브라우저로 열고 **게임 시작** 버튼을 누르면 됩니다.

## 게임 규칙

- 방향키(↑ ↓ ← →)로 고양이를 조종합니다.
- 물고기를 먹으면 고양이가 길어지고 +10점입니다.
- 벽이나 자기 몸에 부딪히면 게임 오버입니다.
- 최고 점수는 브라우저 LocalStorage에 저장되어 새로고침 후에도 유지됩니다.

## 기능

- **캔버스:** 400x400, 20x20 격자. 고해상도 화면에서도 선명하도록 벡터로 그린 고양이와 물고기
- **난이도 선택:** 쉬움 330ms / 보통 250ms (기본값) / 어려움 170ms / 매우 어려움 80ms (한 칸 이동 간격)
- **레벨 시스템:** 50점마다 레벨업, 레벨업 시 이동 간격이 10ms씩 짧아집니다 (최소 30ms)
- **일시정지:** 버튼 또는 스페이스바로 일시정지/재개, 버튼 텍스트도 함께 변경
- **효과음:** 물고기를 먹을 때 소리가 나며, 소리 켜기/끄기 버튼으로 조절 (설정은 LocalStorage에 저장)
- **다시 시작:** 게임 오버 화면에서 다시 시작 버튼 제공

## 파일 구조

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 구성 (캔버스, 점수판, 버튼) |
| `style.css` | 스타일 |
| `main.js` | 게임 로직 |
